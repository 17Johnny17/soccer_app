## Repository Expectations

### Code Generation & Modifications
When creating, refactoring, or modifying code in this repository, you must adhere to the following guidelines:

* **Justify Changes:** Provide a clear explanation of *why* the code was written or modified.
* **Document Decisions:** Detail the technical design choices, trade-offs, and architectural decisions made during development.
* **Maintain Quality:** Ensure all code aligns with the existing architecture, styling conventions, and testing standards of this project.
